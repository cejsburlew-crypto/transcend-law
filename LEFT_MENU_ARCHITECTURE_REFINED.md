## Data Model: Core vs. Specialty

### Database Schema Addition

```sql
CREATE TABLE tools_core (
  id SERIAL PRIMARY KEY,
  tool_key VARCHAR(100),
  tool_name VARCHAR(255),
  persona_id INT REFERENCES personas(id),
  tool_order INT,
  category VARCHAR(50),
  is_core BOOLEAN DEFAULT true,
  created_at TIMESTAMP
);

CREATE TABLE tools_specialty (
  id SERIAL PRIMARY KEY,
  tool_key VARCHAR(100),
  tool_name VARCHAR(255),
  persona_id INT REFERENCES personas(id),
  practice_area_id INT REFERENCES practice_areas(id),
  tool_order INT,
  category VARCHAR(50),
  is_specialty BOOLEAN DEFAULT true,
  created_at TIMESTAMP
);

-- OR: Single table with is_core flag
CREATE TABLE tools (
  id SERIAL PRIMARY KEY,
  tool_key VARCHAR(100),
  tool_name VARCHAR(255),
  persona_id INT REFERENCES personas(id),
  practice_area_id INT REFERENCES practice_areas(id), -- NULL for core
  tool_order INT,
  category VARCHAR(50),
  is_core BOOLEAN DEFAULT false, -- true = appears for all this persona
  created_at TIMESTAMP
);
```

### Query for Left Menu

```sql
-- Get left menu for Lawyer specializing in Corporate Law

-- PART 1: Core tools (appear for all lawyers)
SELECT tool_name, tool_order, category
FROM tools
WHERE persona_id = 2 (Lawyer)
  AND is_core = true
  AND practice_area_id IS NULL
ORDER BY category, tool_order;

-- Result: 22 universal lawyer tools (Legal Research, Billing, etc.)

-- PART 2: Specialty tools (Corporate Law specific)
SELECT tool_name, tool_order, category
FROM tools
WHERE persona_id = 2 (Lawyer)
  AND is_specialty = true
  AND practice_area_id = 5 (Corporate Law)
ORDER BY category, tool_order;

-- Result: 10-15 Corporate Law specialized tools
```

### Query for Different Specialist

```sql
-- Same lawyer user, but viewing Family Law menu

-- PART 1: Core tools (same as before)
SELECT tool_name, tool_order, category
FROM tools
WHERE persona_id = 2 (Lawyer)
  AND is_core = true
ORDER BY category, tool_order;

-- Result: 22 universal lawyer tools (unchanged)

-- PART 2: Specialty tools (Family Law instead)
SELECT tool_name, tool_order, category
FROM tools
WHERE persona_id = 2 (Lawyer)
  AND is_specialty = true
  AND practice_area_id = 2 (Family Law)
ORDER BY category, tool_order;

-- Result: 12-15 Family Law specialized tools (different from Corporate)
```

## Implementation: Render Left Menu

### Frontend Component Structure

```typescript
// src/components/LeftMenu/DynamicLeftMenu.tsx

export interface DynamicLeftMenuProps {
  personaId: number;
  practiceAreaId?: number; // User's specialty (if applicable)
}

export const DynamicLeftMenu: React.FC<DynamicLeftMenuProps> = ({ 
  personaId, 
  practiceAreaId 
}) => {
  // Load core tools
  const coreTools = useQuery({
    queryKey: ['coreTools', personaId],
    queryFn: () => fetchCoreTools(personaId)
  });
  
  // Load specialty tools (if practice area selected)
  const specialtyTools = useQuery({
    queryKey: ['specialtyTools', personaId, practiceAreaId],
    queryFn: () => practiceAreaId 
      ? fetchSpecialtyTools(personaId, practiceAreaId)
      : Promise.resolve([]),
    enabled: !!practiceAreaId
  });
  
  return (
    <nav className="left-menu">
      {/* CORE SECTION */}
      <section className="menu-section core">
        <h3>Core Tools</h3>
        {coreTools.data?.map(tool => (
          <MenuItemCore key={tool.id} tool={tool} />
        ))}
      </section>
      
      {/* SPECIALTY SECTION */}
      {specialtyTools.data && specialtyTools.data.length > 0 && (
        <section className="menu-section specialty">
          <h3>{getPracticeAreaName(practiceAreaId)} Workflows</h3>
          {specialtyTools.data.map(tool => (
            <MenuItemSpecialty key={tool.id} tool={tool} />
          ))}
        </section>
      )}
    </nav>
  );
};
```

## Benefits of Two-Tier Structure

✅ **Consistent Core Experience:** Every lawyer sees same universal tools  
✅ **Specialized Workflows:** Each practice area has tailored tools  
✅ **Easy Switching:** Lawyer can switch practice areas, menu updates  
✅ **Scalable:** Add new practice areas without touching core  
✅ **Manageable:** Small core menu (5-8 sections) + focused specialty section  
✅ **Discoverable:** Users see only relevant tools for their practice
