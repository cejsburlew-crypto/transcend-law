## 🧪 HANDS-ON LABS

### Lab 1: Environment Setup

**Duration:** 30 minutes

```
1. Clone GitHub repository
2. Set up local development environment
3. Configure environment variables
4. Start Docker containers
5. Access local app: http://localhost:3000
6. Make a test API request
```

### Lab 2: Trace API Request

**Duration:** 45 minutes

```
1. Open monitoring dashboard
2. Observe live API requests
3. Pick one request to trace
4. Follow through application logs
5. Check database query logs
6. Understand complete flow
```

### Lab 3: Incident Simulation

**Duration:** 60 minutes

```
1. Simulate high CPU usage
2. Trigger auto-scaling
3. Observe scaling in action
4. Verify system stability
5. Monitor recovery
6. Document findings
```

### Lab 4: Deploy a Hotfix

**Duration:** 90 minutes

```
1. Create small bug fix
2. Write unit test
3. Commit to feature branch
4. Create pull request
5. Get code review
6. Deploy to staging
7. Verify fix works
8. Deploy to production
```
