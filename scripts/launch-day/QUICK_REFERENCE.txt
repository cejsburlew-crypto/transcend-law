EMERGENCY PROCEDURES SUMMARY
================================================================================
Elevated Error Rate:
  1. Check CloudWatch logs
  2. Review Sentry errors
  3. Check database connections
  4. If persists >2 min → ROLLBACK

API Connectivity Loss:
  1. Check ALB status
  2. Verify target instances
  3. Check security groups
  4. If cannot connect → ROLLBACK

Database Connection Errors:
  1. Check connection count
  2. Review database logs
  3. Check network connectivity
  4. If persistent → Consider ROLLBACK

CloudFront/CDN Issues:
  1. Check cache hit rate
  2. Verify S3 bucket
  3. Review error logs
  4. Invalidate cache if needed

QUICK TROUBLESHOOTING
================================================================================
DNS Not Resolving:
  dig production.transcendlaw.com @8.8.8.8
  → Wait 60+ seconds after DNS change
  → Clear local DNS cache

AWS CLI Not Found:
  which aws
  → Install: curl "https://awscli.amazonaws.com/awscli-exe-macos-x86_64.zip" -o "awscliv2.zip"

Scripts Not Executable:
  chmod +x *.sh
  → Re-run scripts

Permission Denied on AWS:
  aws sts get-caller-identity
  → Verify AWS credentials and IAM permissions

API Returns 500:
  Check application logs on EC2 instances
  → SSH to instances: ssh -i key.pem ec2-user@<instance-ip>
  → Review /var/log/application.log
