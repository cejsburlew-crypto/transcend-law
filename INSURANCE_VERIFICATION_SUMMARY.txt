BACKEND SERVICE FUNCTIONS
================================================================================

1. uploadInsuranceCertificate()
   - Validates coverage amounts vs state requirements
   - Stores certificate with metadata
   - Returns InsuranceCertificate object

2. verifyInsuranceCertificate()
   - Manual or API verification
   - Updates certificate status
   - Creates verification record
   - Logs audit trail

3. performQuarterlyVerification()
   - Finds certificates due for re-verification
   - Attempts automatic verification via API
   - Marks at-risk certificates
   - Alerts providers of failures

4. processExpiredInsurance()
   - Daily check for expired certificates
   - Auto-revokes provider access
   - Creates suspension records
   - Sends notifications

5. getComplianceStatus()
   - Returns comprehensive status object
   - Calculates risk score
   - Generates flags and recommendations
   - Tracks next verification date

6. recordClaimHistory()
   - Records malpractice claims
   - Tracks claim status changes
   - Logs claim amount

7. getClaimsHistory()
   - Retrieves 5-year claim history
   - Filters by claim status
   - Orders by date

================================================================================
INSURANCE CERTIFICATE STATUSES
================================================================================

pending   - Awaiting verification
verified  - Approved and valid
expired   - Expiration date passed
invalid   - Failed verification
revoked   - Access revoked, insurance lapsed

================================================================================
COMPLIANCE STATUSES
================================================================================

compliant    - All requirements met, insurance valid
at-risk      - Certificate pending verification or issues detected
non-compliant - No active insurance or verification failed
suspended    - Access revoked due to expired/lapsed insurance

================================================================================
RISK SCORING FACTORS
================================================================================

0-25:   Low Risk (fully compliant)
25-50:  Moderate Risk (minor issues)
50-75:  High Risk (significant issues)
75-100: Critical Risk (non-compliant or suspended)

Factors contributing to risk score:
- No active insurance (+40 points)
- Certificate not verified (+20 points)
- High claims count (>5 in 5 years) (+15 points)
- Verification overdue (+10 points)
